# Brand assets

The project uses an original SelectionExplainer mark, generated on 2026-10-30 with the built-in imagegen tool. It combines text-selection brackets, short text strokes and an explanation bubble. It is not the SoftJL logo.

- `logo.png`: selected transparent-background generated artwork for repository presentation.
- `app.ico`: 256-pixel Windows icon export of the same artwork, embedded by the build script.

Prompt used:

> Use case: logo-brand. Asset type: original desktop app icon and GitHub README logo for SelectionExplainer, a tiny Windows tool that automatically explains highlighted text. Create a polished, memorable minimal geometric brand mark: a pair of selection brackets enclosing two short text strokes, cleverly integrated with a small explanation speech bubble. Crisp bold silhouette readable at 24px, elegant balanced negative space, subtle teal-to-blue color, flat vector-like finish, centered within a softly rounded square. Transparent space outside the rounded square. No letters, no words, no gradients outside the icon, no mockup, no extra objects, no watermark. Square 1024x1024 composition with generous 10% safe margin. Distinctive original mark, not copied from another product.

The design was generated for this repository; no external product logo was used as an input. These files are project assets distributed with this repository's license; trademark rights are not granted by Apache-2.0.
