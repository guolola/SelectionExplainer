SelectionExplainer - Windows x64 Preview

Run SelectionExplainer.exe on Windows 10/11 x64 with .NET Framework 4.8.
Configure your API base URL, model and key, then select text with the mouse.
Double-click the tray icon for settings, or right-click to pause/exit.

The default interface and explanation prompt are Simplified Chinese.
Only applications exposing a Windows UI Automation text selection are supported.
Selected text is sent to the model service you configure. No explanation history
is saved. The preview executable is not code-signed.

运行 EXE，配置模型后鼠标选中文字即可自动解释。托盘右键可暂停或退出。
要求 Windows 10/11 x64 和 .NET Framework 4.8。选中文字会发给你配置的模型。
